# ADR-034: Frontend, UI/UX & Web Domain SOTA Hardening

## 1. Context and Problem Statement

Following the completion of Batches 1, 2, 3, and 4 (ADR-030 through ADR-033), **Batch 5 (Frontend, UI/UX & Web)** governs user interfaces, web standards, accessibility, mobile ergonomics, and visual design.

While the catalog baseline is solid, forensic audit in [`COGNITIVE_DEBT_RELATIONAL_GRAPH.md`](./skills/COGNITIVE_DEBT_RELATIONAL_GRAPH.md) identified key domain debts:
1. **`react-best-practices`:** Lacks React 19 Server Components (RSC) vs Client Component boundaries, Server Actions, Compiler memoization, and `use()` hook invariants.
2. **`ui-ux-pro-max`:** Missing mathematical WCAG 2.2 AAA color contrast formulas ($C_{\text{ratio}} \ge 7:1$) and CSS fluid clamp equations (`clamp(min, val, max)`).
3. **`mobile-design`:** Lacks touch target minimum geometry constraints ($48 \times 48\text{dp}$ / $44 \times 44\text{pt}$), Apple HIG / Material Design 3 guidelines, and offline-first state sync.
4. **`seo-optimizer`:** Lacks JSON-LD Schema.org structured data graph objects, Core Web Vitals (CWV: INP, LCP, CLS) performance budgets, and canonical meta protocols.
5. **`artifacts-builder`:** Lacks single-file self-contained HTML/CSS/JS sandbox architecture, strict Content Security Policy (CSP), and reactive state without external build tools.
6. **`ux-researcher-designer`:** Lacks System Usability Scale (SUS) calculation formulas ($\text{SUS} \ge 68$) and Nielsen Norman Group 10 Usability Heuristics scoring.

## 2. Decision Drivers

- **Modern Web Standards:** Full alignment with React 19, WCAG 2.2 AAA accessibility, and Schema.org JSON-LD graphs.
- **Cognitive Ergonomics & Ergonomic Physics:** Mathematical touch target bounds, fluid typography, and SUS scoring.
- **Target Grade:** Elevate all 6 skills in Batch 5 to **Grade B+ / A / S (Target Catalog Average > 85.8)**.

## 3. Considered Options

- **Option A (Stylistic Guidelines):** Generic CSS and React tips. (Rejected).
- **Option B (Formal Mathematical Models & React 19 Standards — Quadra Tier II):** Ingest WCAG 2.2 contrast math, React 19 RSC boundaries, SUS calculation formulas, and Schema.org graph schemas. (Accepted).

## 4. Decision Outcome

**Chosen Option:** Option B. Formulate and implement the complete Quadra Decision Set (ADR-034, ADR-034-BP, ADR-034-PI, ADR-034-TODO) for Batch 5.

### 4.1 Positive Consequences
- Zero accessibility regressions with automated WCAG 2.2 contrast validation.
- Modern React 19 patterns eliminating unnecessary re-renders and client bundle bloat.
- Self-contained browser artifacts that execute cleanly without build tools or external vulnerabilities.
- Systematic UX research grounded in empirical SUS scoring.

### 4.2 Negative Consequences / Trade-offs
- Strict touch target geometry requires minimum 48px padding around interactive mobile elements.
