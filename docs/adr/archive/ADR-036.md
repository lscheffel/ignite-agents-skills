# ADR-036: Meta-Skills, Bootstrapping & SDLC Lifecycle Domain SOTA Hardening

## 1. Context and Problem Statement

Following the consolidation of Batches 1 to 6 (ADR-030 to ADR-035), **Batch 7 (Meta-Skills, Bootstrapping & SDLC Lifecycle)** governs the skills that build, audit, discover, release, and document skills and repositories across the entire ecosystem.

Forensic analysis in [`COGNITIVE_DEBT_RELATIONAL_GRAPH.md`](./skills/COGNITIVE_DEBT_RELATIONAL_GRAPH.md) identified specific domain debts:
1. **`skill-audit-bulletin`:** Lacks formal ADR generation handoff thresholds and continuous audit ledger delta drift triggers.
2. **`skill-creator`:** Lacks strict token ceiling enforcement ($\le 4,000$ tokens per `SKILL.md`) and progressive disclosure structural linting.
3. **`skill-discovery`:** RAG semantic routing lacks Reciprocal Rank Fusion (RRF) combining BM25 keyword frequency and vector cosine similarity.
4. **`find-skills`:** Lacks FTS5 trigram tokenization, query expansion algorithms, and sub-millisecond fallback ladders.
5. **`git-workflow`:** Lacks Trunk-Based Development short-lived branch rules ($T_{\text{branch}} \le 24\text{h}$) and rebase vs merge invariants.
6. **`repo-bootstrap`:** Lacks canonical 6-Pillar repository governance scaffolding (SECURITY.md, CODE_OF_CONDUCT.md, LICENSE).
7. **`release`:** Lacks SLSA Level 3 supply chain security standards and automated cryptographic artifact signing (GPG/Cosign).
8. **`technical-documentation`:** Lacks 6-Pillar SSOT documentation reconciliation matrix and Mermaid architecture rendering rules.
9. **`verification-before-completion`:** Lacks mandatory automated test runner execution verification gate before declaring task done.
10. **`writing-skills`:** Lacks strict Agent Skills Specification (v1.0.0) compliance rules, typed YAML frontmatter, and progressive disclosure.

## 2. Decision Drivers

- **Meta-Governance Excellence:** Guarantee that meta-skills strictly enforce standards on other skills without cognitive drift.
- **Supply Chain Security & Traceability:** SLSA Level 3, Trunk-Based Development, and 6-Pillar SSOT documentation reconciliation.
- **Zero Grade C Skills:** Elevate 100% of the repository's 60 skills to **Grade B or higher (Target Catalog Average > 86.8)**.

## 3. Considered Options

- **Option A (Loose Meta Guidance):** Generic templates without strict token budgets or mathematical rank fusion. (Rejected).
- **Option B (Formal Mathematical Models, Token Ceilings & Security Gates — Quadra Tier II):** Ingest Reciprocal Rank Fusion, Token Budgets, SLSA Level 3, Trunk-Based Development, and Agent Skills v1.0.0. (Accepted).

## 4. Decision Outcome

**Chosen Option:** Option B. Formulate and implement the complete Quadra Decision Set (ADR-036, ADR-036-BP, ADR-036-PI, ADR-036-TODO) for Batch 7.

### 4.1 Positive Consequences
- 100% of the catalog (60/60 skills) achieves Grade B+ / A / S SOTA status with zero Grade C or failing skills.
- RAG skill discovery achieves state-of-the-art hybrid precision via Reciprocal Rank Fusion ($K=60$).
- Robust software supply chain governance with SLSA Level 3 attestation and Trunk-Based Git discipline.

### 4.2 Negative Consequences / Trade-offs
- Mandatory verification before completion prevents declaring tasks complete without passing test runs.
