# Release Checklist Template

## Pre-Release

- [ ] CHANGELOG.md updated
- [ ] Version bumped
- [ ] Tests pass
- [ ] Lint passes
- [ ] Build functions
- [ ] Security scan

## Publication

- [ ] Tag created
- [ ] npm publish
- [ ] Docker push
- [ ] GitHub Release

## Post-Release

- [ ] Users notified
- [ ] Documentation updated
- [ ] Version for dev incremented
